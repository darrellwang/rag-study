## RAG 学习环境部署

为用户在 WSL 中部署了 LangChain + LangGraph + RAG 学习环境，连接 Windows 上 LMStudio 提供的本地大模型。

### 环境信息
- WSL Python 3.12.3
- LMStudio 通过 `localhost:1234/v1` 提供 OpenAI 兼容接口（WSL 镜像网络模式，可直连）
- 默认对话模型：`qwen/qwen3.6-35b-a3b`
- 默认 Embedding 模型：`text-embedding-embeddinggemma-300m`（768 维）

### 项目位置
`/home/darrell/workspace/rag-study/`

### 关键踩坑与解决方案
1. **SOCKS 代理拦截 localhost**：WSL 配置了 `ALL_PROXY=socks5://127.0.0.1:7890`，httpx 经代理访问 localhost 报错。解决：`config.py` 中 httpx 客户端设 `trust_env=False`。
2. **Embedding 格式不兼容**：`OpenAIEmbeddings` 默认 `check_embedding_ctx_length=True` 会发 token ID 数组，LMStudio 只接受字符串，报 400。解决：关闭该选项。
3. **Chroma 弃用警告**：改用独立包 `langchain-chroma`（`from langchain_chroma import Chroma`）。
4. **路径定位**：`config.py` 基于 `__file__` 定位项目根目录，确保跨目录运行也能找到 `.env`。

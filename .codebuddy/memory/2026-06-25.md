# 2026-06-25 工作日志

## 新增 4 个 LangChain/LangGraph 应用场景

在现有 4 个脚本基础上，新增 4 个场景脚本，覆盖更多典型用法。

### 新增脚本
1. **`src/05_tool_use.py`** — LangChain 工具调用 (Function Calling)
   - 注册 4 个工具：calculate/get_current_time/roll_dice/get_weather
   - 模型自主决定何时调用工具，演示 Agent 基础能力

2. **`src/06_multi_agent.py`** — LangGraph 多智能体协作
   - 研究→写作→审校三角色协作，审校不达标退回重写
   - 修复了一个关键 bug：reviewer 节点不能同时有无条件边和条件边，否则条件边返回 END 时仍会走无条件边导致死循环

3. **`src/07_map_reduce_summarize.py`** — Map-Reduce 长文档摘要
   - 对比 Stuff 和 Map-Reduce 两种策略
   - 注意：LangChain 1.0+ 移除了 `load_summarize_chain`，改用 LCEL 手动构建链

4. **`src/08_workflow_router.py`** — LangGraph 条件路由
   - LLM 分类 → 路由到 4 条分支（技术/创意/数学/闲聊）
   - 每条分支有专门处理逻辑

### 踩坑记录
- **LangChain 1.0+ 移除 `langchain.chains`**：`load_summarize_chain` 不再可用，需用 LCEL 手动实现 Map-Reduce
- **LangGraph 条件边与无条件边冲突**：同一节点的无条件边会覆盖条件边，导致条件返回 END 时仍执行下一节点。解决方案：只保留条件边，不加无条件边

- `README.md` 增加了 4 个新脚本的说明表格和详细工作流流程图

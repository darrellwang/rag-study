## Codex CLI 配置连接本地 LM Studio
- 版本: codex-cli 0.116.0 (支持 responses wire API)
- 配置文件: ~/.codex/config.toml
- LM Studio base_url: http://localhost:1234/v1, wire_api="responses"
- provider ID: lmstudio-local (lmstudio 是内置保留 ID，不能覆盖)
- 环境变量 LMSTUDIO_API_KEY="lmstudio" 已添加到 ~/.bashrc
- model = "qwen/qwen3.6-35b-a3b"
- 手动指定模型元数据: context_window=131072, supports_reasoning_summaries=false
- 非内置模型需在 config.toml 顶层手动设置 model_context_window 等元数据字段
- Codex 版本升级: 0.116.0 -> 0.142.2
- npm 有两个全局路径: ~/.npm-global 和 nvm 默认路径，PATH 中 ~/.npm-global/bin 优先
- ~/.npm-global/bin/codex 是符号链接指向 nvm 路径下的实际文件
- npm install -g 安装到 nvm 路径，升级时需要用 --prefix ~/.npm-global 或重建符号链接
